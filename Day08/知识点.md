# Day08 知识点

## 一、模拟题是什么

照题意一步步仿真实现，不考特定算法，考三件事：
1. 题意读准（操作顺序、边界条件）
2. 数据结构选对（数组 / 字典 / 队列）
3. 细节写细（下标、输出格式、状态更新时机）

死法固定：题意漏条件、状态更新顺序错、边界差一。

## 二、四件武器

### 1. 当前指针 + 取模回绕（约瑟夫环）
- 圈用列表表示，出列就 pop
- 出列者下标 `i = (i + m - 1) % len(alive)`，报数起点 m-1 由"报 1 的人下标 + m - 1"推来
- **删完不动下标**：pop 后下一个人补位到 i，取模自动处理回绕
- `while alive:` 优于 `while alive != []`

### 2. 方向数组（网格类万能框架）
- 右下左上 = 0,1,2,3：`dx = [0,1,0,-1]`，`dy = [1,0,-1,0]`，两个数组下标必须对齐
- 右转 90°：`d = (d + 1) % 4`；左转：`d = (d + 3) % 4`
- 螺旋四步循环：① 填当前格 → ② 试探下一步 → ③ 不通就转向重算 → ④ 挪过去
- 试探条件四项全查：`nx < 0 or nx >= n or ny < 0 or ny >= m`，**放在碰格子之前**

### 3. 行列对应（易错点）
- 地图 n 行 m 列：行下标受 n 约束，列下标受 m 约束
- 起点 1 开始计数 → 存入 0 开始网格要 -1，输出再 +1

### 4. 服务/流水线模拟（奶茶店）
- 不用 0/1 表达窗口忙闲，用一个数字 `cur` = 窗口到哪一刻才空
- 每人开始时刻统一式子：`start = max(cur, t)`，再 `cur = start + c`
- 输入不保证按时间递增 → 先排序：`(t, c, i)` 三元组捆绑，`key=(x[0], x[2])`（时间优先、同 t 编号小优先）
- 输出按编号 → `ans = [0] * n`，`ans[原编号] = start`，不能按处理顺序 append

## 三、踩坑记录（6 条）

1. **`[[0]*n]*n` 是引用复制**：n 行是同一个列表，改一格全变；元素是可变对象（列表/字典）且要原地修改时，必须用列表推导式 `[[0]*n for _ in range(n)]` 重新构造
2. **先查边界，再碰格子**：`and` 短路求值从左往右，越界检查必须在 `grid[nx][ny]` 之前，否则 IndexError（本日两次踩中：螺旋、机器人）
3. **越界上界用 `>= n` 不是 `> n`**：下标合法范围 0~n-1
4. **Python 负下标不报错**：`grid[-1]` 静默回绕到最后一行，比崩溃更危险，下界必须显式查
5. **排序必须捆绑元组整体排**：单独排一个字段（如只排 t）会把配对拆散，排完 c 就不是原来那个人的了
6. **"跑过样例"≠"写对了"**：样例可能恰好不触发 bug（n==m 时行列用反不炸、输入恰好有序时排序 key 错也对），要靠读代码 + 自测边界用例（如"从最底行朝下走"）验证
